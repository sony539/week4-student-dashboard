# Student Management Dashboard

A front-end CRUD application to manage student records, built as the Week 4 capstone project of my web development internship.

## Features
- Add, edit and delete student records
- Data stored in browser localStorage (persists after refresh)
- Styled responsive table
- Live search by name or roll number
- Filter by branch

## Tech Stack
HTML, CSS, JavaScript
